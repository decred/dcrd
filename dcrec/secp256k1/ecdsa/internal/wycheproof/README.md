wycheproof
==========

## Overview

This package contains test vectors from
[Project Wycheproof](https://github.com/C2SP/wycheproof) for testing secp256k1
ECDSA signature verification.

The vectors are used to help ensure the ECDSA implementation correctly handles a
variety of valid and invalid signatures, including edge cases involving
signature encoding and signature values.

The test vectors are obtained from the following Wycheproof JSON files:

- `ecdsa_secp256k1_sha256_test.json` - Standard ECDSA test vectors.
- `ecdsa_secp256k1_sha256_bitcoin_test.json` - Bitcoin-specific ECDSA test
  vectors.

The standard vectors test ECDSA verification without enforcing low-S signatures,
while the Bitcoin-specific vectors additionally enforce the low-S restriction.

These vectors are intended to complement the extensive unit tests in the parent
`ecdsa` package by providing an additional source of independently maintained
test cases.

## Updating the Test Vectors

The test vectors are generated by `genwycheproof.go` from the upstream
Wycheproof JSON files.

The generator pins a specific Wycheproof commit and verifies the SHA-256 hash of
each downloaded file to ensure the generated vectors correspond to the expected
source contents.

To update the vectors:

1. Update `wycheproofCommit` and the associated expected SHA-256 hashes in
   `genwycheproof.go`.
2. Run `go generate` from this directory to download and generate the updated
   vectors.

The generator automatically removes duplicate test cases across the source files
for each public key, so no manual selection or deduplication of test case
identifiers is necessary.
